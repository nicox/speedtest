WAN Acceptance Reference Endpoint

Infrastructure host. Not a public service.

This site exists so that newly installed WAN circuits can have their internet throughput measured against a fixed endpoint outside the corporate network. It is used by the acceptance tool during line handover.

PathPurpose
/payload.bin20 MiB incompressible file, fetched repeatedly to measure download throughput
/healthplain-text liveness check

The payload is fetched repeatedly across parallel connections rather than downloaded once. On a gigabit circuit a single 20 MiB transfer completes inside TCP slow start, which would measure the protocol ramp instead of the line.

Measurements taken here reflect the path to the nearest Cloudflare location, which may differ between sites and over time. The acceptance tool records which location served each run so that later comparisons stay honest.

Contact your network team before changing anything here — recorded acceptance results depend on this endpoint behaving consistently.
